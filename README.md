# Portfolio - Eliot Burgalat

Bienvenue sur le dépôt de mon portfolio personnel. Ce site présente mon parcours, mes compétences et mes projets en tant qu'étudiant en développement logiciel à l'IMT Atlantique.

🔗 **Voir le site en ligne :** [https://beliote.github.io](https://beliote.github.io)

## 🛠 Technologies utilisées

* **HTML**
* **CSS**
* **JavaScript**
* **Design** : "Mobile First" et responsive.

## 🚀 Fonctionnalités

* Design moderne et minimaliste.
* Mode sombre (Dark Theme) par défaut.
* Animations fluides au défilement et au survol.
* Section Projets dynamique.

## 📦 Installation locale

Si vous souhaitez cloner ce projet pour le tester localement :

1.  Clonez le dépôt :
    ```bash
    git clone [https://github.com/beliote/beliote.github.io.git](https://github.com/beliote/beliote.github.io.git)
    ```
2.  Ouvrez le fichier `index.html` dans votre navigateur.
